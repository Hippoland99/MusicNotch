# 🎵 MusicNotch

A minimal, lightweight macOS media controller living directly under your MacBook notch. Built with Swift & SwiftUI.

## ✨ Features
- **Zero Distraction:** Lives invisibly directly under the hardware notch and only expands on hover.
- **Universal Support:** Controls **Spotify**, **Apple Music**, and **YouTube Music** (in Safari).
- **Native & Snappy:** Pure SwiftUI using non-activating panels (never steals focus from your IDE).
- **Clean Background Utility:** No dock icon, no app-switcher clutter (`accessory` mode).

## ⚙️ Requirements
- macOS with Apple Silicon (Notch recommended)
- For YouTube Music (Safari): Check *Develop -> Allow JavaScript from Apple Events* in Safari.
